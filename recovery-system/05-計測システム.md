# 05 — 計測システム（1日3分・続けられる記録）

> このシステム全体の心臓部。**測れないものは改善できない**し、原因も特定できない。
> 制約：1日**3分以内**（朝1分＋夜2分）。ADHD前提なので**項目を絞り・選択式・スマホでもできる**設計。
> 鉄則：**完璧な記録より、ガタガタでも続く記録**。飛んだ日は空欄でOK。

---

## 何を測るか（最小セット）

「全部測る」と続かない。**原因特定に必要な最小項目**だけに絞る。

### 朝（起きてすぐ・1分）
| 項目 | 入力 | 意味 |
|---|---|---|
| 起床体調 | 1–5 | 「朝スッキリ」のゴール指標。一番大事な数字 |
| 睡眠の質（体感） | 1–5 | 時間でなく"回復感" |
| 夜間の中断回数 | 数字 | 授乳/中途覚醒。交絡フラグにもなる |
| 就寝/起床時刻 | 時刻 | リズムの一貫性チェック |

### 夜（寝る前・2分）
| 項目 | 入力 | 意味 |
|---|---|---|
| 日中の眠気 | 1–5（5=眠くない） | ゴール指標 |
| 夕方〜帰宅後のエネルギー | 1–5 | 「帰宅後も元気」のゴール指標 |
| 集中力 | 1–5 | brain fog の指標 |
| 食事フラグ | 該当に✓ | 小麦/砂糖/揚げ物/加工/酒（犯人特定用） |
| 夜スマホ時間 | 分 | スクリーンタイムから転記 |
| 運動 | ○/× | Week5以降 |
| ひとことメモ | 自由 | 特記事項（強いだるさ、いいこと, etc） |

> スコアは深く考えず**直感で1–5**。一貫していればOK（自分内の相対比較が目的）。

---

## どう測るか（ツールは"摩擦最小"で選ぶ）

ADHDの継続には「開くのが面倒」が最大の敵。**いま一番開く頻度が高い場所**に置く。おすすめ順：

1. **スマホのメモ/リマインダーに固定テンプレ**：`templates/daily-log.md`をコピーして毎日複製。
   - ただし`03`でスマホを遠ざけるので、**朝晩の記録だけは許可アプリにする**か、下記2を推奨。
2. **紙＋ペンを枕元に**：スマホ追放(`03`)と相性最高。チェックを書くだけ。最も摩擦が低い人が多い。
3. **スプレッドシート**：`templates/daily-log.csv`をGoogleスプレッドシートに読み込み→自動でグラフ化したい人向け。
4. **習慣トラッカーアプリ**（数値記録できるもの）でもよい。

> どれでもいい。**続く場所**が正解。凝ったシステムを作ること自体が目的化しないよう注意（ADHDの罠）。

### 自動で取れるものは自動で
- **スマホのスクリーンタイム**：手入力せず、夜に数字だけ転記（または週次レポートのスクショ保存）。
- **スマートウォッチ/リング所持なら**：睡眠段階・血中酸素・心拍は自動取得。手入力は主観スコアだけに。

---

## 運用ルール（続けるための設計）

- **記録のトリガーを既存習慣に紐付け**：朝＝「目覚まし止めた直後」、夜＝「歯磨きの後」。場所と時刻を固定。
- **3分を超えたら項目を削る**。続かない設計は無意味。コア指標（起床体調・日中眠気・夕方エネルギー・食事フラグ・スマホ時間）だけでも価値がある。
- **飛んだ日は空欄**。埋め戻さない。罪悪感で辞めるのが最大のリスク。
- **1日単位で一喜一憂しない**。判断は必ず**7日移動平均/週次レビュー**で。

---

## 週次レビュー（週1回・5分）

データは「見返して初めて意味を持つ」。`templates/weekly-review.md`で週末に5分：

1. **トレンド確認**：起床体調・日中眠気・夕方エネルギーの今週平均は、先週/Week0比でどう動いた？
2. **相関を1つ探す**：「食事フラグが多い翌日は起床体調が低い？」「スマホ時間が多い日と睡眠の質の関係は？」
3. **交絡の除外**：夜間授乳で中断が多かった日を分けて見る。
4. **次週に変える変数を1つだけ決める**（`00`の段階に従う）。

---

## 答え合わせ（このシステムのゴール）

3ヶ月後、Week0ベースライン vs 直近の7日移動平均を比較し、**数字で**ゴール達成を判定する：

| 指標 | Week0平均 | 目標 |
|---|---|---|
| 起床体調 | （記入） | ≥ 4.0 |
| 日中の眠気（5=眠くない） | （記入） | 改善（眠い日50%減） |
| 夕方エネルギー | （記入） | ≥ 3.5 |
| 夜スマホ時間 | （記入） | 50%減 |
| 疲労の主犯 | 不明 | **特定できた**（食事/睡眠/医療のどれか言える） |

> このシステムの真の成果物は「体調が良くなった"気がする"」ではなく、
> **「自分の疲労はこれが原因で、これをやれば回復する」と数字で言い切れること**。
