# 02 — 睡眠プラン（時間ではなく「質」を上げる）

> あなたの核心症状：**8〜9時間寝ても回復しない**。
> これは「時間不足」ではなく「**質の低下＝深睡眠（デルタ波）に落ちきれていない**」を強く示唆する。
> よって本プランは**時間を増やすことを目的にしない**。質＝デルタ波到達にフォーカスする。

---

## 最重要：脳が夜「シャットダウン」できていない（主仮説）

> 痩せ型・いびきほぼ無のKenでは、無呼吸の確率は低い。最有力は**交感神経が休まらず脳がデルタ波に落ちない**こと。
> 理論と対策テクニックの本体は **`06-研修ナレッジ.md`**（ドクター遠藤のリーダーズ研修）に集約。ここでは睡眠特化で要点のみ。

```
未解決の問題・ストレス → 脳が寝ても「シータ波（問題解決）」で動き続ける
→ 回復の「デルタ波」に到達できない → 脳の洗浄「大フラッシュ」不発 → 朝だるい
```

### デルタ波に落とすための核心アクション（`06`から）
- **就寝前ブレインダンプ**：頭に残るタスク・悩みを紙に全部書き出す。「明日やる」と外部化＝脳のシータ波ループを止める。**最優先**。
- **就寝前デジタルデトックス＋15分瞑想**：スマホを止め（`03`）、目を閉じ「はー」呼吸。
- **「はー」呼吸**：口をリラックスさせ温かい息を吐く＝副交感神経ON。布団の中で数回。
- **デルタ波到達のサイン**：朝「目やに/よだれ」＝深睡眠に入れた証拠。`05`で簡易チェック。

### 無呼吸は念のため1度だけ確認（優先度・低）
痩せ型・いびき無なら確率は低いが、ゼロではない。**いびき録音アプリ（SnoreLab等）を2〜3晩**回し、妻に夜間の呼吸を確認してもらえば十分。明確ないびき/無呼吸の指摘があった時だけ睡眠外来へ。なければこの線は閉じてよい。

## 睡眠の質を上げる仕組み（環境設計ベース）

意志力ではなく環境で。効果が高い順。

### 1. 光のコントロール（体内時計の最強レバー）
- **朝**：起きたら数分でも屋外/窓際の光を浴びる（育児の朝に抱っこで外に出るだけでOK）。体内時計をリセットし、夜の眠気を正しい時刻に来させる。
- **夜**：就寝1–2時間前から部屋を暗く・暖色に。天井の白色灯を消し、間接照明/暖色に。
- **寝室は真っ暗**：遮光・LEDの光点をテープで隠す。アイマスクも安価で有効。

### 2. 体温リズム（深睡眠を増やす）
- **就寝90分前に入浴**（ぬるめ）。一度上げた深部体温が下がる過程で深く眠れる。
- 寝室はやや涼しく。暑いと深睡眠が減る。

### 3. カフェイン/アルコールのタイミング（質の天敵）
- **カフェインは午後は摂らない**（半減期が長く、自覚なく睡眠の質を削る）。目安：昼以降ゼロ。
- **アルコールは睡眠の質を確実に下げる**。寝つきは良くても後半の睡眠が浅くなる→「寝たのにだるい」の主因になりうる。平日ゼロを推奨。

### 4. 就寝前の入力遮断
- **夜スマホが質を壊している**前提（`03`参照）。ブルーライト以上に「脳の覚醒」が問題。
- 寝床に入ってからのスマホをゼロにする＝`03`の環境設計で物理的に実現。

### 5. 一貫性（新生児期の現実解）
- 理想は毎日同じ時刻だが、新生児期は不可能。**起床時刻だけ揃える**ことを優先（光を浴びる時刻を固定するとリズムが保てる）。
- 夜間授乳で分断されるのは仕方ない。**分断された夜はログに「中断」フラグ**を立て、施策評価から分けて見る（`00`の交絡対策）。

## 新生児期の"睡眠負債"への現実的対応

第二子誕生直後で、そもそも連続睡眠が取れない時期。完璧な睡眠衛生は無理。優先順位を割り切る：

1. **無呼吸スクリーニングだけは必ずやる**（生活でどうにもならない要因なので）
2. **朝の光＋夜の暗さ**（コスト最小・効果大）
3. **午後カフェイン断ち・夜アルコール断ち**（やめるだけ・コストゼロ）
4. **戦略的仮眠**：日中に取れるなら**20分以内**の仮眠（それ以上は夜に響く）。妻と交代でまとまった睡眠を取れる日を週に作れないか設計（環境=家庭の運用で解決）。

## 計測との連動

`05`で毎日とる「起床時スコア・夜間中断回数・就寝/起床時刻」を、施策投入の前後で7日移動平均比較。
**「夜まわり改善で起床スコアが上がるか」が、睡眠が主犯かどうかの答え**になる。
上がらなければ → 医療要因（無呼吸/甲状腺/鉄など）の比重が高い、と判断できる。
