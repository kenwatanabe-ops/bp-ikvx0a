## 🎯 ゴール（現状の外）と、自分への宣言

**「私は、朝スッキリ目覚め、日中も帰宅後も高エネルギーで、家族と事業を前に進める人間である。」**

- 完璧主義は捨てる。記録が飛ぶ日・できない日があってOK。**やめないことだけが条件。**

## 全体の地図（なぜこの順番か）

研修の公式 **脳疲労 = 情報処理 ＋ 炎症 − 回復**。これを上から順に潰す：

```
Phase 0  計測の土台        ← 何も変えず1週間記録（before証拠）
Phase 1  回復を増やす(夜)   ← 主仮説直撃。無料・高効果。脳をデルタ波に落とす
Phase 2  情報処理を減らす   ← スマホ/ドーパミン。スパイク→ベースライン置換
Phase 3  炎症を減らす(食)   ← 4毒の除去→再導入で犯人特定（CGM併用）
Phase 4  回復の仕組み化     ← S-S-R(支援・解放)・運動・戦略的休養
Phase 5  恒久システム＋答え合わせ
```

各フェーズは**「次へ進む条件」を満たしたら次へ**。何ヶ月かかってもいい。重なってもいい。

### 午前/午後リズムを前提にする（再現性のある発見）
朝が底・午後に回復。これを敵でなく前提に：**午前は軽負荷（重要判断を入れない）／午後に最重要タスク・難しい会話を寄せる／朝はケアで立ち上げる**。daily-logは「午前エネルギー」と「午後エネルギー」を分けて記録（→`07-生活設計`）。

### 到達目標（2週 / 1ヶ月 / 3ヶ月）＝依頼①コンディション改善計画
| | 到達したい状態 | 主に動かすPhase |
|---|---|---|
| **2週** | 計測が回る／夜デトックス＋ブレインダンプが習慣化／起床スコアが少し上向く | Phase0+1 |
| **1ヶ月** | スマホ夜時間が半減／回復枠がカレンダーに固定／疲労時の標準食が常に在る | Phase1-2＋`07``08` |
| **3ヶ月** | 朝スッキリの日が増える／食事の主犯を特定／回復が"制度"として回る | Phase3-5 |

> この実行プランは6つの依頼に対応：①=この表＋Phase全体／②食事=Phase3＋`08`／③生活設計・④回復固定化=`07`／⑤原因特定=`00`。

# Phase 0 — 計測の土台（まず1週間）

**目的**：before を取る。これが無いと「効いた」が永久に分からない。**何も変えない。ただ記録するだけ。**

### 一度だけ仕込む
- [ ] アナログ目覚まし時計を注文（スマホ目覚ましを卒業する布石）
- [ ] CGM（持続血糖測定／Abbottリブレ等）を手配（Phase3で使う）
- [ ] 今のスマホのスクリーンタイム週次レポートをスクショ保存（before証拠）
- [ ] `daily-log` を置く場所を決める（枕元に紙＋ペンが最強）

### 毎日
- [ ] 7日間、生活を変えずに daily-log を記録（朝1分・夜2分）
- [ ] アファメーションだけは今日から開始

### ✅ 次へ進む条件
- 7日中5日以上 記録できた／起床スコア・日中眠気・夕方エネルギーの7日平均が出た

# Phase 1 — 回復を増やす：夜と脳のシャットダウン（主仮説の直撃）

**狙い**：交感神経過剰でデルタ波に落ちない＝「寝ても回復しない」を直す。**無料・最高効果。ここが本丸。**

### 一度だけ仕込む（環境）
- [ ] スマホの充電場所を**寝室の外**に固定（目覚ましはアナログ）
- [ ] 寝室を**真っ暗・21-23度**に（遮光・LED光点を隠す・アイマスク）
- [ ] 就寝1.5h前から間接照明/暖色に

### 毎日（習慣・既存動作に紐付け）
- [ ] **就寝前ブレインダンプ＋HLBLT**：未解決タスク/悩みを紙に全部出す＋High/Low/Learning/Thanks（脳のシータ波ループを止める＝最優先）
- [ ] **就寝1.5h前デジタルデトックス**＋布団で**「はー」呼吸/4-7-8呼吸**
- [ ] **朝**：起きて数分、屋外/窓際の光（抱っこ散歩でOK）
- [ ] ナイトルーティンを**できる範囲で**（入浴でふくらはぎまで温め／瞑想5分／口テープで鼻呼吸 など `02`参照）

### 観察
- [ ] 朝「目やに/よだれ」が出たか（=デルタ波到達のサイン）を daily-log に

### ✅ 次へ進む条件
- 起床スコアの7日平均が Phase0比で**+0.5以上** or 目やに/よだれサインの日が増えた
  → 改善＝主仮説が正しい。改善が薄ければ Phase2/3 の比重を上げる（どのみち次へ進む）

---

# Phase 2 — 情報処理を減らす：スマホ／ドーパミン置換

**狙い**：「疲れる→スマホ→さらに疲れる」のスパイク依存ループを、**環境とベースライン置換**で断つ（意志力ゼロ）。

### 一度だけ仕込む（環境）
- [ ] スマホを**グレースケール**常時オン
- [ ] SNS/動画/ニュースを**ホームから削除**（できればアンインストール）
- [ ] **通知を全部オフ**（家族など必須の人だけ残す）
- [ ] スクリーンタイムの**ダウンタイム自動ロック**（就寝1h前〜起床30分）。**パスコードは妻に設定してもらう**（疲れた自分が解除できない）

### 毎日（置換＋フィジオロジー）
- [ ] **朝のスマホ → 散歩に置換**（散歩しながら→散歩のみ→瞑想 へ段階移行）
- [ ] **反芻/スマホ逃避の衝動 → デスクから物理的に離れる・ジャンプ3回**（考えるな、動け）
- [ ] 日中に詰まったら**視野を広げる（パノラマ視）/「はー」呼吸**
- [ ] 可能なら**15-20分パワーナップ**（小フラッシュ）

### ✅ 次へ進む条件
- 夜のスクリーンタイムが Phase0比で**30%以上減**／日中眠気スコアが改善傾向

---

# Phase 3 — 炎症を減らす：食事（4毒の除去 → 再導入）

**狙い**：「ピザ翌日brain fog」の犯人を**推測でなく実験**で確定する。Phase1-2で体力が戻ってから着手（食事はやや意志力が要るため）。

> 前提：除去をやる前に **`08-食事システム`** を立てる（常備在庫・標準食A/B・宅食つくりおき.jpの定期便）。「疲れた時の標準食」が無いと除去は続かない。

### ステップA：除去（washout・約2週間）
- [ ] **4毒＋酒を一旦すべて外す**：小麦・植物性油（揚げ物/加工）・乳製品・砂糖・アルコール
- [ ] 同時に**CGM装着**：何を食べると血糖が跳ねるか可視化
- [ ] 置換で乗り切る（コーヒー→お茶／ラーメン→十割そば／酒→炭酸水）＝禁欲でなく置換

### ステップB：再導入（1つずつ・3日間隔）
- [ ] washoutで調子が上がったら、**小麦→砂糖→揚げ物/油→酒→乳製品** の順に1つずつ戻し、当日＋翌日48hの症状を記録
- [ ] 強く反応した食品＝あなたの**主犯**。それだけ恒久排除（家に置かない）

### ✅ 次へ進む条件
- 「主犯食品」を1つ以上特定できた／除去期に起床・集中スコアが動いた（＝食事の寄与が分かった）

# Phase 4 — 回復の仕組み化：S-S-R・運動・戦略的休養

**狙い**：疲労の構造的な根＝**ストレス過多 × サポート/リリース不足（バーンアウト）**を埋める。ここからは"続ける"フェーズ。

### サポートを増やす（Support）
- [ ] 抱えている仕事/役割を**1つ、誰かに振る or 相談する**（15分でも）。自分のSupportも設計対象。

### リリースを毎日入れる（Release）
- [ ] **毎日、汗をかく or 感情を紙に書き殴る**（Releaseは脳を強化する）
- [ ] **戦略的休養を予定に入れる**：マイクロ(日5-20分×2-3)／中(週 半日-1日)／大(月 旅行)

### 運動を1種目だけ（habit-stack）
- [ ] **抱っこ散歩 or 歯磨き後スクワット10回** を1つだけ固定（場所と時刻を固定／`04`）
- [ ] 座りっぱなしを潰す（1時間に1回立つ・通話は歩きながら・食後10分歩く）

### 回復をカレンダーに固定する（→ `07-生活設計`／本質的課題への対策）
- [ ] **週次・大回復枠を固定**（例：毎週土8:00-10:00 サウナ/散歩/整体）＝毎回の交渉を無くす
- [ ] **夫婦設計**：妻の自由枠を先に固定し、自分の枠とセットで制度化（共有カレンダーに可視化）
- [ ] 回復枠は**スキップ禁止・移動のみ可**

### 負荷そのものを減らす（パレート）
- [ ] 毎朝、その日の**最重要タスク1つ**を決めてカレンダーをブロック
- [ ] 低価値タスクを1つ「やめる/減らす/自動化」

### ✅ 次へ進む条件
- 夕方エネルギーの7日平均が**3.5以上**／週次レビューでSupport・Releaseが毎週入っている

# Phase 5 — 恒久システム化＋答え合わせ

**狙い**：効いた施策を"意志力ゼロで戻らない形"に固定し、**何が主犯だったかを数字で言い切る**。

- [ ] 効いた施策を環境化（主犯食品を家に置かない／充電場所固定／ナイトルーティン定着）
- [ ] **Phase0 vs 現在**の7日平均を比較（下の答え合わせ表）
- [ ] **疲労の主犯ランキング**を確定（例：①交感神経/夜スマホ ②小麦 ③…）
- [ ] 残る不調があれば、それを次の検証対象に（=自分専用OSの継続運用へ）

## 続けるための保険（ADHD前提）

- **週1の週次レビュー（5分）**：`templates/weekly-review.md`。トレンド確認＋来週変える1変数を決める。
- **詰まったら**：そのフェーズの「毎日やること」を**半分に減らす**。0にしない。
- **再発したら**：このプランに戻る。一度効いた施策は再現できる＝それが"システム"。
- 合言葉：**「エントロピーは自然、複雑化は意図」**。何もしなければ戻る。少しのエネルギーを毎日。
