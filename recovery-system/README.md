# Ken専用 回復システム（Recovery System）

> 目的：慢性的な疲労・眠気・集中力低下の**原因を特定**し、**最小コストで回復力を最大化**する。
> 単なる健康改善ではなく、**事業・育児・人生パフォーマンスを最大化するための自分専用OS**を構築する。

---

## ⚠️ 最初に読む（重要）

このドキュメント群は**医療行為ではなく、自己実験（セルフトラッキング）の設計図**です。
ただし、あなたの状況には「自己実験の前に、まず医者で潰すべき項目」があります。

**8〜9時間寝ても3年間ずっとだるい** ——これは生活習慣だけでは説明しきれないことが多く、
以下は**安価で・1回の血液検査＋問診でほぼ判明する**ため、**着手1〜2週目で並行して潰す**ことを最優先で推奨します。

| 疑う対象 | なぜ | どうする |
|---|---|---|
| 鉄欠乏（フェリチン低下） | 男性でも起こりうる。だるさ・brain fog の典型原因 | 血液検査で**フェリチン**を測る（通常の貧血検査だけでは見逃す） |
| 甲状腺機能低下 | 疲労・眠気・集中力低下の代表格 | **TSH, FT4** を測る |
| ビタミンD欠乏 | 日本人に非常に多い。疲労・気分low | **25(OH)D** を測る |
| ビタミンB12欠乏 | brain fog・倦怠感 | 血液検査 |
| 血糖異常 | ピザ翌日のだるさと整合 | **HbA1c・空腹時血糖** |
| 睡眠時無呼吸 / UARS | 「寝ても回復しない」の最有力 | 後述（02-睡眠プラン参照）。スクリーニング→必要なら検査 |
| うつ・適応障害 | 起業＋産後＋育児の負荷で十分起こりうる | 問診。隠さず相談する |

👉 **アクション：今週中に内科を1回予約し、「慢性疲労。フェリチン・TSH・FT4・25(OH)D・B12・HbA1c・血算を調べたい」と伝える。**
これだけで「治せる原因」が見つかれば、以下のプラン全部より早く効きます。

## 設計思想（ここが一番大事）

あなたはADHD傾向があり、**意志力依存の施策は必ず失敗する**前提で設計しています。
全プランは次の5原則に従います。

1. **環境設計 > 意志力**
   「我慢する」ではなく「そもそも選択肢を物理的に消す/遠ざける」。
   例：夜スマホを我慢する → ✕／寝室にスマホを持ち込めない仕組みを作る → ◯

2. **デフォルト化（初期値の力）**
   健康な選択を「何もしなくてもそうなる」状態にする。
   例：冷蔵庫にジャンクを入れない＝意志力ゼロで食べない。

3. **摩擦の設計**
   悪い行動に摩擦を足し、良い行動から摩擦を取る。
   例：スマホをモノクロ＋アプリ削除（摩擦+）／運動着を枕元に置く（摩擦-）。

4. **単一変数で検証**
   全部同時に変えると「何が効いたか」永久に分からない。
   1度に変える変数を絞り、計測で答え合わせする（00-原因特定プラン参照）。

5. **最小コスト・継続可能性最優先**
   新生児＋産後ケア＋起業中。完璧を狙うと0になる。
   **「70点を毎日」＞「100点を3日で挫折」**。すべて"忙しい日でも回る最小版"を用意。

## 全体ロードマップ（3ヶ月）

```
Week 0      ベースライン計測（何も変えない。ただ記録する1週間）＋ 病院予約
Week 1-2    環境を仕込む：睡眠環境・スマホ環境・計測習慣を固定 ＋ 食事ドラマチックテスト
Week 3-4    食事の除去→再導入で犯人特定（elimination & reintroduction）＋ 睡眠検査
Week 5-8    効いた施策を「システム化」して固定 ＋ 運動を導入
Week 9-12   自律神経・ストレス対策を上乗せ。指標トレンドで効果確定。恒久システム化
```

## ゴール（3ヶ月後の状態）

- [ ] 朝スッキリ起きる（起床時の体調スコア平均 ≥ 4/5）
- [ ] 日中眠くない（日中眠気の日数 50%減）
- [ ] 帰宅後もエネルギーが残る（夕方のエネルギースコア平均 ≥ 3.5/5）
- [ ] スマホ依存改善（夜のスクリーンタイム 50%減）
- [ ] 疲労の原因を**特定できた**（食事/睡眠/医療要因のどれが主犯か言える）

> ゴールは「主観で何となく良くなった」ではなく、**05の計測データのトレンドで証明する**。
