# Ken専用 回復システム（Recovery System）

> 目的：慢性的な疲労・眠気・集中力低下の**原因を特定**し、**最小コストで回復力を最大化**する。
> 単なる健康改善ではなく、**事業・育児・人生パフォーマンスを最大化するための自分専用OS**を構築する。

---

## ⚠️ 最初に読む（重要）

このドキュメント群は**医療行為ではなく、自己実験（セルフトラッキング）の設計図**です。

> **前提（Kenの状況）**：過去に血液検査を何度か受けているが異常なし。
> → 本人の見立て通り、**「標準的な血液検査では数値に出ないタイプの原因」**を主軸に置く。
> 一般的な血液パネルは正常でも、**血糖の"動き"・睡眠中の呼吸・自律神経・食物過敏**などは捉えられない。
> 血液検査の話は後ろに小さく回し、まず "検査で出てこない領域" から潰す。

**8〜9時間寝ても3年間ずっとだるい** ——血液が正常なら、原因は次の「血液検査では絶対に見えない領域」にある可能性が高い。
これらを**着手1〜2週目から並行して**潰していく。

| 疑う対象（血液では見えない） | なぜ最有力か | どう確かめるか |
|---|---|---|
| **睡眠時無呼吸 / UARS** | 「何時間寝ても回復しない」の最有力。血液検査では一生分からない。まさに"検査で出ない"領域 | いびき録音・妻に確認→疑いあれば**睡眠検査**（`02`参照）。今回の主軸候補 |
| **血糖の"動的な"乱れ** | HbA1c（平均値）が正常でも、食後スパイクは別。ピザ翌日のbrain fogと整合 | **CGM（持続血糖測定）を2週間**つけて、何を食べると乱れるか可視化（`01`参照）。検査で出ない領域の本命 |
| **自律神経の乱れ（交感神経優位）** | 起業＋産後＋育児で慢性的に休まっていない。数値に出にくい | 心拍変動(HRV)を時計/リングで観察。`02`の体温/光、Week9以降の対策 |
| **食物過敏・腸内環境** | 標準検査では出ない。除去→再導入でしか分からない | `00`のエリミネーション＆リイントロダクションで犯人特定 |
| **睡眠の質そのもの（深睡眠不足）** | 時間でなく質。血液では分からない | `02`＋`05`の主観スコア＋ウェアラブルで観察 |

👉 **アクション（最優先）：血液検査ではなく、まず①睡眠（無呼吸の有無）と②血糖の動き（CGM）を見る。**
この2つが「血液検査で出てこない部分」の本命。`02-睡眠プラン`と`01-食事プラン`から着手する。

## 設計思想（ここが一番大事）

あなたはADHD傾向があり、**意志力依存の施策は必ず失敗する**前提で設計しています。
全プランは次の5原則に従います。

1. **環境設計 > 意志力**
   「我慢する」ではなく「そもそも選択肢を物理的に消す/遠ざける」。
   例：夜スマホを我慢する → ✕／寝室にスマホを持ち込めない仕組みを作る → ◯

2. **デフォルト化（初期値の力）**
   健康な選択を「何もしなくてもそうなる」状態にする。
   例：冷蔵庫にジャンクを入れない＝意志力ゼロで食べない。

3. **摩擦の設計**
   悪い行動に摩擦を足し、良い行動から摩擦を取る。
   例：スマホをモノクロ＋アプリ削除（摩擦+）／運動着を枕元に置く（摩擦-）。

4. **単一変数で検証**
   全部同時に変えると「何が効いたか」永久に分からない。
   1度に変える変数を絞り、計測で答え合わせする（00-原因特定プラン参照）。

5. **最小コスト・継続可能性最優先**
   新生児＋産後ケア＋起業中。完璧を狙うと0になる。
   **「70点を毎日」＞「100点を3日で挫折」**。すべて"忙しい日でも回る最小版"を用意。

## 全体ロードマップ（3ヶ月）

```
Week 0      ベースライン計測（何も変えない。ただ記録する1週間）＋ 睡眠検査/CGMの手配
Week 1-2    環境を仕込む：睡眠環境・スマホ環境・計測習慣を固定 ＋ 食事ドラマチックテスト
Week 3-4    食事の除去→再導入で犯人特定（elimination & reintroduction）＋ 睡眠検査
Week 5-8    効いた施策を「システム化」して固定 ＋ 運動を導入
Week 9-12   自律神経・ストレス対策を上乗せ。指標トレンドで効果確定。恒久システム化
```
