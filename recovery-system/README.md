# Ken専用 回復システム（Recovery System）

> 目的：慢性的な疲労・眠気・集中力低下の**原因を特定**し、**最小コストで回復力を最大化**する。
> 単なる健康改善ではなく、**事業・育児・人生パフォーマンスを最大化するための自分専用OS**を構築する。

---

## ⚠️ 最初に読む（重要）

このドキュメント群は**医療行為ではなく、自己実験（セルフトラッキング）の設計図**です。

> **前提（Kenの状況）**：過去に血液検査を何度か受けているが異常なし。
> → 本人の見立て通り、**「標準的な血液検査では数値に出ないタイプの原因」**を主軸に置く。
> 一般的な血液パネルは正常でも、**血糖の"動き"・睡眠中の呼吸・自律神経・食物過敏**などは捉えられない。
> 血液検査の話は後ろに小さく回し、まず "検査で出てこない領域" から潰す。

**8〜9時間寝ても3年間ずっとだるい** ——血液が正常で、いびきもほぼ無く、痩せ型（＝無呼吸の可能性も低い）。
だとすれば、最有力は **「脳が夜にシャットダウンしきれていない（＝深睡眠＝デルタ波に落ちきれていない）」** こと。

> **🎯 主仮説（研修ナレッジと一致）**：起業・育児・複数事業の**未解決の問題／慢性ストレス**で交感神経が休まらず、
> 脳が寝ている間も「シータ波（問題解決モード）」で動き続け、回復に必要な「デルタ波」に到達できない。
> デルタ波でだけ起こる脳の老廃物洗浄＝**「大フラッシュ」が不発**→ brain fog・「寝たのに疲れている」。
> これは血液検査にも睡眠時無呼吸検査にも出ない。**Kenの「検査で出ない原因」という直感の正体がこれ。**
> 詳細と対策テクニックは **`06-研修ナレッジ.md`**（ドクター遠藤のリーダーズ研修より）。

| 疑う対象（血液では見えない） | なぜ最有力か | どう確かめる／対処 |
|---|---|---|
| **🥇 自律神経の乱れ（交感神経優位でデルタ波に落ちない）** | 未解決問題が多い生活そのもの。Kenの状況と研修理論が完全一致 | `06`の呼吸法・ブレインダンプ・瞑想で副交感神経に切替→`05`で起床スコアの変化を見る |
| **睡眠の質そのもの（深睡眠不足）** | 時間でなく質。血液では分からない | `02`＋`05`の主観スコア＋（あれば）ウェアラブルの深睡眠時間 |
| **血糖の"動的な"乱れ** | HbA1c（平均値）が正常でも、食後スパイクは別。ピザ翌日のbrain fogと整合 | **CGM（持続血糖測定）を2週間**つけて可視化（`01`参照） |
| **食物過敏・腸内環境** | 標準検査では出ない。除去→再導入でしか分からない | `00`のエリミネーション＆リイントロダクションで犯人特定 |
| 睡眠時無呼吸 / UARS | 「寝ても回復しない」の典型だが、Kenは痩せ型・いびき無で**確率低** | 念のため いびき録音で1度だけ確認すれば足りる |

👉 **アクション（最優先）：`06-研修ナレッジ.md`の「最優先で試す3つ」（就寝前ブレインダンプ／デジタルデトックス＋15分瞑想／日中の"はー"呼吸＋視野を広げる）から着手する。**
これが「検査で出てこない原因」＝交感神経過剰への直接対策。並行して血糖の動き（CGM）も見る。

## 設計思想（ここが一番大事）

あなたはADHD傾向があり、**意志力依存の施策は必ず失敗する**前提で設計しています。
全プランは次の5原則に従います。

1. **環境設計 > 意志力**
   「我慢する」ではなく「そもそも選択肢を物理的に消す/遠ざける」。
   例：夜スマホを我慢する → ✕／寝室にスマホを持ち込めない仕組みを作る → ◯

2. **デフォルト化（初期値の力）**
   健康な選択を「何もしなくてもそうなる」状態にする。
   例：冷蔵庫にジャンクを入れない＝意志力ゼロで食べない。

3. **摩擦の設計**
   悪い行動に摩擦を足し、良い行動から摩擦を取る。
   例：スマホをモノクロ＋アプリ削除（摩擦+）／運動着を枕元に置く（摩擦-）。

4. **単一変数で検証**
   全部同時に変えると「何が効いたか」永久に分からない。
   1度に変える変数を絞り、計測で答え合わせする（00-原因特定プラン参照）。

5. **最小コスト・継続可能性最優先**
   新生児＋産後ケア＋起業中。完璧を狙うと0になる。
   **「70点を毎日」＞「100点を3日で挫折」**。すべて"忙しい日でも回る最小版"を用意。

## 全体ロードマップ（3ヶ月）

```
Week 0      ベースライン計測（何も変えない。ただ記録する1週間）＋ CGMの手配
Week 1-2    主仮説への直撃：研修の「最優先3つ」(ブレインダンプ/夜デトックス+瞑想/はー呼吸)＋スマホ環境＋計測習慣
Week 3-4    食事の除去→再導入で犯人特定（elimination & reintroduction）＋ CGMで血糖の動き＋日中パワーナップ
Week 5-8    効いた施策を「システム化」して固定 ＋ 運動・筋膜・朝瞑想を導入
Week 9-12   残った不調に上乗せ対策。指標トレンドで効果確定。恒久システム化
```

> 自律神経対策（研修ナレッジ）は当初Week9以降の予定だったが、**主仮説に格上げしWeek1から着手**する。
