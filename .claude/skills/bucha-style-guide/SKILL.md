# BUCHA スタイルガイド

`index.html` のコピーを書く・編集するときは以下に従う。

## 表記
- 数字は半角。単位の前にスペースは入れない（例: `30%`, `1,000円`）。
- 英数字と日本語の間のスペースは入れない（用語の見栄え優先で統一）。
- 固有名詞「BUCHA」は常に大文字。

## トーン
- 投資家・パートナー向け。誇張を避け、根拠（数字・出典）とセットで主張する。
- 一文を長くしすぎない。結論→理由の順。

## やらないこと
- 裏付けのない断定（「業界No.1」等）を根拠なしに書かない。
- `robots.txt` の noindex 方針を崩す変更（公開範囲に関わる変更）は事前確認する。

> このファイルはテンプレートです。実プロジェクトのルールに合わせて加筆してください。
